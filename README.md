# itberg.tn

Site vitrine d'**ITBerg** : IA souveraine et agents, applications Android et iOS, sécurité.
« L'IA en surface. La maîtrise en profondeur. »

- `public/` : le site, en HTML, CSS et un peu de JavaScript, sans framework.
- **Publication automatique** : chaque pull request reçoit un aperçu Firebase, et chaque fusion sur `main` publie sur https://itberg.tn, puis prévient les moteurs (IndexNow).
- `scripts/check_site.py` : vérifications lancées avant chaque publication (liens, titres, descriptions, données structurées).
- Guides : [NOTICE.md](NOTICE.md) pour modifier et publier, [SEO.md](SEO.md) pour le référencement et les statistiques.
