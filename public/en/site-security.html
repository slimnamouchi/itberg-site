Transparency

This site is secure: check it yourself

We audit the security of our clients’ apps. Our own site should lead by example, and you should be able to check it without taking our word for it.

What we have put in place

HTTPS everywhere, and only HTTPS

Every page is encrypted. Browsers are told (HSTS) never to fall back to an unencrypted connection for a year, on the domain and its subdomains.

A strict Content Security Policy

The CSP starts from “nothing is allowed” (default-src 'none') and opens only what is needed: our own scripts, our own styles and our images. No inline code, no unsafe-inline, no eval.

Trusted Types

The browser refuses any raw HTML written by a script (require-trusted-types-for 'script'). This is the most effective protection against DOM-based XSS. Our scripts only use safe methods.

No third-party scripts

No CDN, no external fonts, no widgets, no social buttons. All code comes from our own server, so nothing external can be changed behind our back.

No cookies, no forms

The site sets no cookies and asks for no data. Audience measurement is anonymous (a single GoatCounter pixel, no cookie), and it switches off if your browser sends Do Not Track or Global Privacy Control.

Protection against framing and snooping

The site cannot be shown inside another site (anti-clickjacking), it is isolated from other tabs (COOP, CORP), and access to the camera, microphone or location is disabled by default.

Controlled publishing

Every change goes through a reviewed pull request, then automated checks: security headers, links, accessibility and performance. If a check fails, the change does not go live. Publishing tools are pinned to an exact version and only have the permissions they need.

An open door for researchers

We publish a security.txt file (RFC 9116) and a responsible disclosure policy.

Check it live

We do not copy a score here: a copied score can be wrong or out of date. Each link runs an independent test on itberg.tn, right now.

  • securityheaders.com tests HTTP security headers.
  • Mozilla HTTP Observatory tests the Content Security Policy, HSTS, redirections and cookies.
  • Qualys SSL Labs tests HTTPS encryption and the certificate.
  • internet.nl tests modern standards: IPv6, DNSSEC, HTTPS.
  • internet.nl (e-mail) tests how our e-mail address is protected against spoofing: SPF, DKIM, DMARC.
  • DNSViz tests the domain’s DNSSEC signature chain.
  • Blacklight (The Markup) tests trackers, third-party cookies and browser fingerprinting.

You can also open your browser’s developer tools (F12), “Network” tab: you will see that every file comes from itberg.tn, and that the only outside request is the anonymous audience pixel.

Our limits, honestly

No security is absolute. This site is hosted on Firebase Hosting (Google): we benefit from its infrastructure but we do not control it. If you find a weakness, we want to know.
