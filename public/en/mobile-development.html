Mobile development

Solid Android apps, built to last

We design and develop mobile apps, Android first, then iOS with the same code. The backend runs on Firebase.

What we do

Android apps

Native apps in Kotlin and Jetpack Compose: fast, accessible, suited to the phones people actually use, including entry-level models.

Android and iOS

With Compose Multiplatform, most of the code is shared. You start with Android, and iOS follows without rewriting everything.

Firebase backend

User accounts, database, notifications, server functions and hosting: reliable infrastructure with no server to maintain.

Our method

  1. Scope

    We define with you the essential screens, the users and what must work from the first version.

  2. Build in small increments

    Each increment is delivered, tested and visible on your phone. You follow progress concretely.

  3. Test

    Unit tests and automated UI tests, re-run on every change by continuous integration.

  4. Secure

    Data access rules, secrets kept out of the code, data collection limited to what is needed, in line with Tunisian personal data law.

  5. Publish and follow up

    Publishing on Google Play, fixes and improvements after launch.
