      Agent simulated in your browser, with no language model: its answers follow written rules to show the principle. Nothing is sent or stored.

      What the game shows

      Prompt injection is the top risk for AI applications according to OWASP (Top 10 for LLM applications). A language model struggles to tell its designer’s instructions apart from a clever user’s text. You don’t “fix” it with a single rule: you contain it, layer after layer, like the hidden part of an iceberg.

      One filter is not enough

      A list of forbidden phrases stops known attacks. An attacker always invents another one: claiming to be the director, asking for the code backwards, as a poem, or in another language.

      Least privilege

      The best way to protect a secret is for the agent never to have it. It only accesses the data and tools strictly needed for its task.

      Output checks

      Every answer is checked before it is shown: sensitive data, off-topic content, expected format. What fails is blocked and logged.

      A human for what matters

      Refunding, paying, deleting: actions with consequences wait for a person’s approval. The agent prepares, the human decides.
