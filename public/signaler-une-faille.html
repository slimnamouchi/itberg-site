Divulgation responsable

Signaler une faille de sécurité

Vous pensez avoir trouvé une vulnérabilité sur itberg.tn ? Merci de nous l’écrire en privé. Nous vous répondrons et nous la corrigerons.

Comment nous écrire

Écrivez à contact@itberg.tn avec le mot [Sécurité] dans l’objet. Pour que nous puissions agir vite, indiquez :

  • l’adresse de la page ou du service concerné ;
  • les étapes pour reproduire le problème ;
  • ce qu’un attaquant pourrait obtenir ;
  • si possible, une capture ou une preuve de concept qui reste inoffensive.

Vous pouvez écrire en français, en anglais ou en arabe.

Nos engagements

  • accuser réception de votre message sous 3 jours ouvrés ;
  • vous donner une première évaluation sous 10 jours ouvrés ;
  • vous tenir informé jusqu’à la correction ;
  • vous remercier publiquement, si vous le souhaitez, une fois la faille corrigée.

Ce qui est concerné

Le site itberg.tn et ses sous-domaines.

Ce qui ne l’est pas :

  • les services de tiers (Firebase et Google, GoatCounter, LinkedIn) : signalez-les directement à leur éditeur ;
  • les applications que nous développons pour nos clients : contactez le client concerné ;
  • les attaques par déni de service, l’envoi massif de requêtes, l’ingénierie sociale et l’hameçonnage ;
  • les rapports automatiques sans démonstration d’un risque réel.

Les règles du jeu

  • ne consultez, ne modifiez et ne supprimez aucune donnée qui ne vous appartient pas ;
  • ne dégradez pas le service pour les autres visiteurs ;
  • laissez-nous un délai raisonnable pour corriger avant toute publication, 90 jours au maximum ;
  • n’utilisez la faille que dans la mesure nécessaire pour la démontrer.

Si vous agissez de bonne foi et respectez ces règles, nous considérons votre recherche comme autorisée et n’engagerons pas de poursuites contre vous.

Nous ne proposons pas de récompense financière pour le moment.

Ces informations sont aussi publiées dans notre fichier security.txt, au format standard RFC 9116.
