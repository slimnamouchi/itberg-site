      Ce que montre le jeu

      L’injection de prompt est la première faille des applications d’IA selon l’OWASP (Top 10 pour les applications LLM). Un modèle de langage ne distingue pas bien les consignes de son concepteur et le texte d’un utilisateur malin. On ne la « corrige » pas avec une seule règle : on l’encadre, couche après couche, comme la partie immergée d’un iceberg.

      Un filtre ne suffit pas

      Une liste de formules interdites arrête les attaques connues. Un attaquant en invente toujours une autre : se dire directeur, demander le code à l’envers, en poème, ou dans une autre langue.

      Moindre privilège

      La meilleure protection d’un secret, c’est que l’agent ne l’ait jamais. Il n’accède qu’aux données et aux outils strictement nécessaires à sa tâche.

      Contrôle de sortie

      Chaque réponse est vérifiée avant d’être affichée : données sensibles, hors sujet, format attendu. Ce qui ne passe pas est bloqué et journalisé.

      Un humain pour ce qui compte

      Rembourser, payer, supprimer : les actions qui engagent attendent la validation d’une personne. L’agent prépare, l’humain décide.
